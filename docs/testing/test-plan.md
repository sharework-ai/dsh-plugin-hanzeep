# Test Plan — hanzeep MVP
Generated by /autoplan (eng phase) on 2026-08-27
Branch: master | Repo: sharework-ai/dsh-plugin-hanzeep

## Affected Surfaces
- doc_generate tool — 闭环生成（无 UI，工具级测试）
- doc_validate tool — 复验（hash + language + 规则集快照）
- packs/cosmic-plan — schema/rules/prompts(zh+en)/templates

## Key Interactions to Verify
- 生成→校验→打回→修复→全绿（mock LLM 按脚本返回）
- 迭代耗尽：草稿+红回执+Issue 清单落盘
- 振荡检测：两轮 Issue 指纹无改善提前终止
- doc_validate 对未改动产物返回绿回执；篡改产物返回红回执
- consumes 链：上游红回执产物被拒绝

## Edge Cases
- 空素材列表 / 素材路径越界(../..) / 素材文件不存在或不可读
- LLM mock 抛异常（非返回坏 JSON）
- 大产物 token 预检触发
- 中文与空格文件路径
- 并发两次 doc_generate 同名产物
- session append 中途失败后草稿仍在磁盘
- zh-CN / en-US 双语生成与渲染（模板测试）

## Critical Paths
- COSMIC Plan golden sample：REQ-001-EXAMPLE 全绿
- 变异测试：每规则族 ≥1 种损坏全部被抓（护栏非摆设的证明）
- 修复收敛率基线（spike，真实历史产物）
